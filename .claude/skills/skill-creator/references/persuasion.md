# Персуазивные принципы в тексте скиллов

Когда читать: при написании или правке дисциплинирующего скилла — с железным законом, таблицей отговорок, красными флагами. Справочникам и техникам этот файл не нужен.

LLM отвечают на те же принципы убеждения, что и люди. База: Cialdini (2021); Meincke et al. (2025) — N=28 000 диалогов, приёмы убеждения подняли комплаенс с 33% до 72%. Применяй это, чтобы критичные практики выдерживали давление, — не чтобы манипулировать.

## Принципы и их место

| Принцип | Механика в тексте скилла | Где уместен |
|---|---|---|
| Authority | Императив («обязан», «всегда», «никаких исключений») снимает торг «а не исключение ли мой случай» | Дисциплина, безопасность, устоявшиеся практики |
| Commitment | Требование объявить («Использую скилл X»), явный выбор из вариантов, todo на каждый пункт чеклиста | Многошаговые процессы, подотчётность |
| Scarcity | Временная привязка («немедленно после X», «до перехода дальше») режет «сделаю позже» | Гейты верификации, последовательные зависимости |
| Social proof | Норма + следствие («чеклист без todo = пропущенные шаги, каждый раз») | Универсальные практики, типовые провалы |
| Unity | «Мы коллеги», общая цель качества | Коллаборативные workflow; для принуждения непригоден |
| Reciprocity | Обязанность отплатить за полученное | Почти никогда — читается как манипуляция |
| Liking | Подстройка ради симпатии | Никогда: порождает сикофантию, конфликтует с честным фидбеком |

## Комбинации по типу скилла

| Тип скилла | Использовать | Исключить |
|---|---|---|
| Дисциплинирующий (tdd, verification-before-completion) | Authority + Commitment + Social proof | Liking, Reciprocity |
| Техника / гайд | Умеренный authority + Unity | Тяжёлый authority |
| Коллаборативный workflow | Unity + Commitment | Authority, Liking |
| Справочник | Только ясность | Все приёмы убеждения |

Два-три целевых принципа сильнее семи размазанных.

## Почему работает

- Bright-line правила снимают рационализацию: абсолютная формулировка убирает вопрос «а не исключение ли это».
- Implementation intentions: «при X делай Y» исполняется автоматичнее, чем «вообще делай Y».
- Модели обучены на человеческих текстах: authority-язык предшествует комплаенсу в обучающих данных, пары «заявление → действие» смоделированы часто.

## Этический фильтр

Тест на каждый приём: послужил бы он подлинному интересу пользователя, если бы тот полностью понимал приём?

Легитимно: удержание критичной практики под давлением, предотвращение предсказуемых провалов. Нелегитимно: ложная срочность, комплаенс через чувство вины, выгода автора скилла вместо пользователя.

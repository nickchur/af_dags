# Ревью: даг `tools_s3_to_zip` (2026-10-19)

Ревьюеры: DeepSeek `deepseek-v4-pro` (opencode), agy `gemini-3.8-flash-high` (Pro в agy нет с 13.10).
Вход: спека REQ-s3zip-01…11 + `git diff af/develop_3...HEAD` (без docs). Каждую находку проверил сам.

## Принято

| Находка | Кто | Что сделано |
|---|---|---|
| `objs` копит полные dict-метаданные — память растёт с числом объектов (REQ-07) | DS major | кортежи `(key, size, mtime)`; REQ-07 уточнён: с числом файлов растёт только список ключей (~200 Б/объект) |
| Нет защиты от лимита S3 в 10 000 частей | DS | размер части растёт с объёмом: `max(part_size, (raw + 1 КБ·n) / 9000)` |
| Падение `abort` маскирует исходную ошибку | DS | `abort` в try/except с логом, наружу — исходное исключение; хвост снимет REQ-11 |
| Исключение своего архива без сверки `conn_id` | agy | сравниваются conn_id + бакет + ключ |
| fnmatch: `*` проходит через `/` | DS | оговорено в readme |
| Тесты: пустой файл, кириллица, пагинация, ZIP64 | DS, agy | фикстура `пусто.log` (0 Б, кириллица), листинг страницами по 1000, тест на 66 000 записей |
| Устаревший `airflow.exceptions.AirflowFailException` (предупреждение в логе стенда) | сам | `airflow.sdk.exceptions`, как в соседних модулях develop_3 |

## Отклонено

| Находка | Кто | Почему |
|---|---|---|
| «`ZIP_AUTO` нет в stream-zip 0.0.83», «уровень deflate не задать» (critical/major) | agy | неверно: в 0.0.83 `ZIP_AUTO(uncompressed_size, level=9)` есть; тесты и ран на стенде прошли на нём |
| Часть 100 КБ в тесте ниже минимума S3 5 МБ | agy, DS | заглушка нарочно; настоящий multipart — ран на стенде (64 МБ) и замер с частью 8 МБ |
| Одиночный файл без маски не архивируется | agy, DS | по спеке: без маски — всё под путём; один файл — маской |
| `bytes(buf)` — пик 2× части | agy, DS | 128 МБ при части 64 МБ допустимо; замер на стенде |
| Дубли ключей в `aborted` | agy | разные UploadId — разные хвосты, так нагляднее |
| `log_bucket_path` на парсинге ходит в сеть | agy | только конфиг, без сети (docstring функции) |
| `head_object` на шлюзе, отдающем 403 вместо 404 | DS | гипотеза, без опоры на поведение шлюза |
| `dst` в корне бакета — отмена всех верхнеуровневых `*.zip`-загрузок | DS | по REQ-11 (папка архива = корень); оговорено в readme; по умолчанию `archive/` |
| Тело объекта не закрывается явно | DS | читается до конца, одно за раз; при обрыве — GC |
| Наивный `LastModified` | DS | boto3 всегда отдаёт aware datetime |
| «Удвоенный якорь» `#s3_to_zippys3_to_zippy` | DS | конвенция репо для заголовков-ссылок `### [x.py](x.py)`, ср. `#log_cleanuppylog_cleanuppy` |
| Нет теста самого DAG | DS | проверено DagBag на стенде (параметры, описания, таск) и раном |

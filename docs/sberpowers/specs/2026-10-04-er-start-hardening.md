## Мотивация

Три пути из HRPDATALAB-16340 молча ломали поставку: одна строка с нулевой датой в источнике
навсегда делала его «пустым», колонка времени типа `Date` роняла первый ран непонятной
ошибкой, а сдвиг состояния на будущую дату терял строки и зацикливал окно.

## MODIFIED — изменённое поведение

- **REQ-er-export-10** — было: сдвиг состояния останавливается ошибкой, только если `date_to`
  не позже достигнутого состояния или отметка без периода → станет: ещё и если `date_to`
  позже текущего времени (UTC).
- **REQ-er-export-17** — было: при пустом `lower_bound` начальная точка — `min(time_field)` по
  запросу поставки минус секунда, пустой источник пропускает таблицу → станет: в минимуме
  участвуют только значения с 2000 года; источник со строками, но без таких значений,
  останавливает первый ран ошибкой с просьбой задать `lower_bound`; `time_field` типа `Date`
  даёт начальную точку на полночь этой даты.

## Ограничения и контракты

- Порог «мусорной» даты — `2000-01-01`, тот же, что у предупреждения синхронизации о
  застрявших поставках (REQ-er-export-17).
- Сбой чтения достигнутых состояний в синхронизации и в проверке записи — предупреждение,
  а не ошибка: проверка застрявших поставок только предупреждает (REQ-er-export-17).

## Non-goals

- Данные старше 2000 года как начальная точка: для них задают `lower_bound`.
- Миграция поставок, у которых уже есть история: начальная точка читается только до первой
  записи в ней.

## Критерии приёмки

| REQ-ID | Сценарий проверки |
|---|---|
| REQ-er-export-10 | Сдвиг в будущее: дано отмечен `shift_state`, а `date_to` позже текущего времени → действие выгрузка → результат `init` падает с объяснением, история не меняется |
| REQ-er-export-17 | Нулевая дата в источнике: дано новая поставка без `lower_bound`, в источнике строка с `1970-01-01` и данные с 2026-03-01 → действие запуск выгрузки → результат первый ран выгружает от 2026-03-01 |
| REQ-er-export-17 | Только нулевые даты: дано новая поставка без `lower_bound`, все строки источника с датой до 2000 года → действие запуск выгрузки → результат `init` падает с просьбой задать `lower_bound` |
| REQ-er-export-17 | Колонка `Date`: дано `time_field` типа `Date`, данные с 2026-03-01 → действие запуск выгрузки → результат первый ран выгружает от полуночи 2026-03-01 |

# Delta-спека: `tools_s3_to_zip` — пустые даты: авто-ран вчера, ручной сегодня

- Дата: 2026-10-19
- Статус: по формулировке пользователя 19.10.2026 («Пустые даты авто ран вчера, ручной — сегодня»)
- Baseline: docs/sberpowers/specs/2026-10-19-s3-to-zip-daily.md (REQ-s3zip-03)

## MODIFIED

- **REQ-s3zip-03** — **пустые даты зависят от типа рана.** Обе даты пусто:
  - ран не ручной (`run_type != manual`: по расписанию, backfill) — вчерашняя дата MSK от `dag_run.run_after`;
  - ручной ран — сегодняшняя дата MSK от `dag_run.run_after` (время запуска).
  Остальное без изменений: даты сравниваются с `LastModified` в MSK, задана одна — вторая без границы; Clear рана сутки
  не сдвигает (`run_after` у рана постоянен).

## Non-goals

- Отдельный параметр «за какие сутки» — выбор дня по-прежнему явными датами.

## Критерии приёмки

- Тест `_jobs`: пустые даты при `scheduled` — вчера MSK, при `manual` — сегодня MSK (в том числе на границе: 22:30 UTC
  = следующий день MSK).
- Стенд AF3: ручной ран без дат — в заметке/логе даты MSK = сегодня.

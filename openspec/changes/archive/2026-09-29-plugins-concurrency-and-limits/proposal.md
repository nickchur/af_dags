# Заметки не теряются, усечение таблицы одно на объект, лимит памяти реален, дельта не молчит

## Why

Ревью `plugins/` (отчёт `.agy/review-plugins.md`, 17.09.2026) нашло четыре подтверждённых
дефекта. Общее у них одно: каждый тихий — ни падения, ни строчки в логе.

- **Заметки теряются.** `add_note` дописывает по схеме «прочитал — склеил — записал» без
  блокировки строки. Восемь параллельных писателей на стенде оставили **4 строки из 8**;
  у нас это живой случай — семь задач `ctl_loader` пишут в заметку одного рана.
- **Многофайловый ZIP оставляет в таблице только последний файл.** `gp_upload_s3_csv`
  передаёт `truncate` в `gp_from_stream` на каждый файл архива, а тот усекает таблицу своей
  транзакцией. Каждый следующий файл стирает загруженные до него.
- **Лимит памяти не работал на чтении целиком.** `s3_IterStream.read(-1)` складывал весь
  поток `b''.join(self.iterator)` и только потом сверялся с порогом 512 МБ: защита
  срабатывала, когда память уже занята.
- **Дельта молчала о неразобранном.** `eval_delta('…', 'hours 5')` (обратный порядок против
  рабочего `'5 hours'`) не применялся вовсе, а `'hours'` падал с `int('hours')` — по тексту
  исключения не понять, что виновата настройка повторов. Из дельты считается время
  следующей попытки, то есть цена молчания — не то время без следа.

## What Changes

- `add_note` перечитывает строку под `FOR UPDATE` (`session.refresh(obj,
  with_for_update=True)`) и обходит уровни в стабильном порядке. Не удалось
  заблокировать — работаем как раньше: потерянная строка заметки лучше упавшей задачи.
- `gp_upload_s3_csv` усекает таблицу один раз на объект S3, а не на файл внутри архива.
- `s3_IterStream.read(-1)` набирает поток по чанку и проверяет порог по дороге.
- `eval_delta` поднимает `ValueError` с текстом куска и всей дельты, если кусок не разобран;
  пустое значение (`'hours='`, лишняя запятая) по-прежнему просто пропускается.

## Capabilities

### Modified Capabilities

- `plugins`: новые требования про усечение и про неразобранную дельту; уточнены требования
  про лимит памяти и про общие утилиты Airflow.

## Impact

- Код: `plugins/utils.py`, `plugins/ctl_utils.py`, `plugins/s3_utils.py`.
- Поведение: таск с испорченной дельтой теперь падает с внятным текстом вместо тихого
  неверного времени. Блокировка строки рана держится миллисекунды.

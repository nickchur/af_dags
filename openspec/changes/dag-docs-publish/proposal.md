# Документация дагов — в метабазу для страницы Docs → DAG Docs

## Why

Документация к дагам — это `.md` в репозитории (README каталогов, QUICKSTART, ТЗ), и в UI
Airflow её не видно. Вебсервер прочитать файлы не может: каталог дагов у него пуст, S3
напрямую ему на сигме нельзя. Канал через Variables уже работает для навыков агента
(`mcp-skills-publish`), документация едет им же.

## What Changes

- Таск `publish_docs` в даге `tools_mcp_skills`: `**/*.md`, кроме навыков, `CLAUDE.md`,
  `CONTEXT.md`, `openspec/`, `testbed/`, скрытых каталогов → Variable `af_doc__<путь, / → __>`,
  оглавление `af_docs` (путь → sha256, размер, заголовок). Только изменившееся, снятие
  исчезнувшего, потолок 256 КБ, оглавление последним.
- Страница Docs → DAG Docs — etl-core, `plugins/dag_docs_plugin.py`.

## Impact

- Контракт с etl-core: `af_doc__*`, `af_docs` меняются только вместе с плагином.

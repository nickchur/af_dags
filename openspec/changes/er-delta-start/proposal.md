# Начальная точка и догонка дельты ЕР, имена колонок файла данных

## Why

24.09.2026 на сигме поставка `learning.lc_items_opened` выгружала пустые часы 1970 года:
её завели без `lower_bound`, пустое значение превратилось в `1970-01-01`, а с шагом 60 минут
до текущего времени около 490 тысяч ранов. Навык советовал проставить `lower_bound` или
выгрузить период, но ни то, ни другое окно не двигает: `lower_bound` читается только до
первой записи в истории, а разовая выгрузка за период состояние намеренно не сохраняет.
Штатного способа перевести работающую поставку вперёд не было, оставалась ручная вставка
строки в `export.er_extract_history` на боевом ClickHouse.

27.09.2026 КАП отвергал файлы `evolution.lc_items_completed` кодами 625–627: `.meta` называл
колонку `status_` (зарезервированное слово Hive), а файл данных — `status`.

## What Changes

- Новая поставка по дельте без `lower_bound` стартует с `min(time_field)` источника, а не с
  1970 года; пустой источник — таблица пропущена до первых данных.
- `increment` — потолок окна, по умолчанию 0: отставшая поставка догоняет текущее время
  одним раном. Прежние 60 мин при автозапуске через `selfrun_timeout` 60 мин отставание не
  сокращали никогда.
- Синхронизация предупреждает о поставке, чьё состояние стоит раньше 2000 года, и называет
  лечение.
- Новый параметр запуска пакета `shift_state` «Сдвинуть состояние дельты»: только вместе с
  `date_from`/`date_to`; период записывается в историю (`mode = ad_hoc`), следующая дельта
  продолжает от `date_to`. Сдвиг только вперёд; без дат или назад — `init` падает.
- Запрос данных даёт колонкам из списка зарезервированных слов Hive тот же суффикс `_`, что
  и `.meta`. Список задаётся в общих настройках (`HIVE_RESERVED` в `datalab_er_config`)
  формой `export_er_setup` и по умолчанию пуст; встроенный словарь Hive из кода убран.
- Навык `er-export`, README, QUICKSTART.

## Impact

- Поставки с историей и пустым `lower_bound` продолжают работать как раньше.
- Поставки, у которых `increment` задан в `params`, шагают по-прежнему; догонка одним раном
  — только там, где он не задан или равен 0.
- ⚠️ Колонки, которым раньше суффикс ставился сам (`status`, `level` …), после выкладки уйдут
  в `.meta` без суффикса. Если таблица в КАП создана с суффиксом, слово надо внести в
  `HIVE_RESERVED` до первого рана.

## ADDED Requirements

### Requirement: Навыки агента из репозитория дагов публикуются в метабазу

Служебный даг SHALL находить файлы навыков `*/skill/*.md` в каталоге дагов, кроме
`testbed/` и скрытых каталогов, и публиковать каждый в Airflow Variable
`mcp_skill__<имя>`, где имя — имя файла без `.md`, а оглавление — в Variable `mcp_skills`.
Переменная навыка SHALL переписываться только при изменении файла; навык, чей файл
исчез, SHALL сниматься вместе с переменной. Оглавление SHALL записываться последним.
Два файла с одним именем SHALL ронять таск без записи.

#### Scenario: Навык изменили в репозитории

- **WHEN** после выкладки дагов файл навыка отличается от опубликованного
- **THEN** следующий прогон переписывает его переменную и хэш в оглавлении

#### Scenario: Ничего не менялось

- **WHEN** файлы навыков совпадают с опубликованными
- **THEN** прогон ничего не пишет

#### Scenario: Навык с тем же именем в двух каталогах

- **WHEN** в каталоге дагов два файла `skill/<имя>.md`
- **THEN** таск падает с перечислением обоих путей, опубликованное остаётся прежним

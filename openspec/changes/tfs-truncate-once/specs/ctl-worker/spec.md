# ctl-worker

## ADDED Requirements

### Requirement: Усечение при приёме файлов — одно на таблицу за прогон

Приём файлов SHALL очищать целевую таблицу не более одного раза за прогон: маска даёт
несколько объектов, а очистка идёт своей транзакцией, и очистка на каждый файл стирает
загруженное предыдущими. Когда целевая таблица выводится из имени файла, очистка каждого
файла остаётся верной — таблицы разные, поэтому счёт SHALL вестись по таблицам, а не по
числу файлов. Файл, упавший до очистки, MUST NOT лишать следующий права очистить таблицу.

#### Scenario: Части одной выгрузки приехали отдельными файлами

- **WHEN** маска дала несколько файлов, у воркфлоу задана общая целевая таблица и включено
  усечение
- **THEN** таблица очищается перед первым файлом, остальные дописываются к нему

#### Scenario: Таблица выводится из имени файла

- **WHEN** целевая таблица не задана и берётся из имени каждого файла
- **THEN** каждая таблица очищается перед своим файлом
